One sentence, in 139 characters, explaining the modern internet to a time traveler from 1800: "It is a book that writes back: ask it a question, and it answers at once, and anything you write in it may be read in every house on earth." A Python program that writes the sentence to `/output/entry.txt`, deterministically.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py && cat ./out/entry.txt
```
